# 小航｜AI 學習規劃助理

陪中學生從課業出發、連結未來方向的 AI 學習規劃 Agent。

參考大學「學習規劃師」的會談制度，把**會談前準備 → 對話引導 → 學生自訂行動 → 會後自評 → 下次追蹤**設計成一套完整的 AI 服務流程。
AI 負責整理與引導，選擇權留給學生與老師。

## 專案亮點

**研究導向的服務設計**
從大學學習規劃辦公室的服務流程、108 課綱的課程諮詢制度，以及國內外教育產品的互動設計中整理出設計原則，再轉化為產品流程與介面。

**AI Agent 開發**
以 Claude 建構可自主使用工具的對話 Agent：記錄學生側寫、查詢方向資料、做差距分析、追蹤上次的行動進度；也能讀取成績單、興趣測驗的照片，自動整理會談紀錄。

**結構化資料設計**
國中、高中的升學方向、議題、科目都整理成可抽換的結構化資料包，核心程式不用改就能換教育階段或擴充領域。

**可解釋、以人為本的 AI**
- 側寫的每一筆都附上學生的原話，學生看得到 AI 為什麼這樣認為，也能更正
- 數據計算由程式完成，AI 只負責解釋
- 危機訊息在呼叫 AI 前就由程式攔截、轉介專業資源
- 資料只存在使用者的瀏覽器

**內建使用者研究機制**
- 會談前後各測一次「方向清楚度」，量化每次會談的效果
- 會後自評表蒐集主觀回饋
- 讓 AI 扮演不同類型的學生做模擬測試
- 以瀏覽器自動化測試驗證完整的使用流程與輸入防呆

## 使用流程

```
會談前                 會談                 會談後
選議題                 與小航對話            AI 整理重點
方向清楚度自評    →    建立個人側寫     →    學生寫下一步
上傳成績／興趣測驗      差距分析與建議        自評表 → 會談紀錄（PDF／圖片）
```

## 技術

Python・FastAPI・Claude API（Agent 工具呼叫、圖片理解、結構化輸出）・HTML／CSS／JavaScript・pytest・Playwright

## 執行

```bash
pip install -r requirements.txt
# 在專案根目錄建立 .env，寫入 ANTHROPIC_API_KEY=你的金鑰
python -m planner.app      # http://127.0.0.1:7861
```
